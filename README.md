# BrainBites Admin Panel - Forest Serenity v1.0.0

The high-fidelity management system for the BrainBites Android application. Built with React, Vite, Tailwind CSS, and Framer Motion.

## 🌿 Visual Identity: Forest Serenity
The Admin Panel is strictly aligned with the official BrainBites brand identity:
- **Forest Green** (`#2D6A4F`): Primary actions and success states.
- **Deep Forest** (`#0F1F17`): Global background for maximum eye comfort.
- **Sage Green** (`#95D5B2`): Secondary accents and typography.
- **Soft Gold** (`#E9C46A`): Achievements and engagement metrics.

## 🚀 Core Features
- **Intelligent Dashboard**: Real-time stats with dynamic counters and engagement trends.
- **Glassmorphism UI**: High-index backdrop blurs and drifting background mesh for a zero-gravity feel.
- **Sequence Repository**: Full management system for Facts and Insights.
- **Wisdom Vault**: Curated psychological quotes management.
- **Identity Hub**: Detailed user profiles with streak tracking and mastery progress.
- **Security Governance**: Multi-role admin management and real-time audit logs.
- **Command Palette**: Global system search with `Ctrl+K`.

## 🛠 Tech Stack
- **Frontend**: React 18, TypeScript, Vite
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **Database**: Firebase Firestore & Auth

## 🏁 Getting Started
1. Clone the repository.
2. Install dependencies: `npm install`
3. Configure `.env` with your Firebase credentials.
4. Launch dev server: `npm run dev`
